# 2026-08-07 — Phase D1: 세션 + 스케줄러 코어 루프

완료 조건이었던 "작업시작 → 프리셋 루틴대로 카드 자동 표시 → 3액션 기록 → 세션 종료" 가
디버그 훅 e2e 로 관통 확인됐다. 하루 풀 세션 도그푸딩 가능 상태.

## 구조 결정: Rust = 시계, TS = 판단

D1 에서 제일 먼저 정해야 했던 것. 스케줄 계산은 CLAUDE.md 규칙상 `src/core/` 순수 함수여야
하는데(모바일 Expo 공유 전제), 그 함수를 **무엇이 주기적으로 돌리느냐**가 문제였다.

JS 타이머로 돌리면 안 된다. 오버레이 웹뷰는 평소 숨겨져 있고, Chromium 은 숨겨진 창의
`setTimeout`/`setInterval` 을 분 단위로 스로틀링한다. 50분 뒤 알림을 `setTimeout` 으로 걸면
언제 깨는지 보장이 없다.

그래서:
- **Rust** — `session.rs` 가 1초마다 `app://tick { now }` 를 오버레이 웹뷰로 보낸다.
  `std::thread::sleep` 은 스로틀링 대상이 아니다. 세션 `startedAt` 의 단일 출처도 Rust
- **TS** — tick 을 받아 `computeNextOccurrences(session, behaviors, startedAt, elapsed, snoozes)` 로
  세션 시작부터 지금까지의 예정분을 뽑고, 아직 안 띄운 것 중 첫 번째를 띄운다

부수 효과로 가상 시각 주입이 공짜로 생겼다. Rust 의 `now_ms()` 에 오프셋 하나만 더하면
`--debug-cmd tick:1800000` 이 "30분 뒤"를 만든다 — 스케줄러의 `now` 주입과 같은 경로라
검증용 샛길이 아니라 실제 경로다.

## 투명 영역 클릭 통과 (「알려진 한계 1」 해소)

원래 계획은 "커서 위치 추적 + `setIgnoreCursorEvents` 토글"이었다. 문제는 클릭 통과를 켜는 순간
그 창은 마우스 이벤트를 못 받으므로 **커서가 다시 카드로 돌아온 걸 감지할 방법이 없다**는 것.
결국 Rust 쪽에서 `GetCursorPos` 폴링 스레드가 필요하다.

대신 차선책으로 적혀 있던 **창을 카드 실크기로 축소**를 택했다. 표시할 때마다 카드를 실측해서
창을 그 크기로 맞춘다(`OverlayWindow.fitWindow`). 폴링도 토글도 없고, 죽은 영역이 줄어드는 게
아니라 **0이 된다**.

대가: 창 밖으로 번지는 드롭섀도가 잘린다. 그림자를 살리려면 그만큼 여백이 필요하고 그 여백이
그대로 죽은 영역이 되므로 맞바꿀 수 없다. 입체감은 테두리 + 안쪽 하이라이트로 대체했다.

함정 하나: **표시가 먼저, 측정이 나중**이어야 한다. 숨겨진 WebView2 는 레이아웃을 돌리지 않아서
`getBoundingClientRect()` 가 전부 0으로 나온다. 처음엔 측정 후 표시 순서로 짰다가
"카드는 발화했는데 창이 안 뜨는" 증상을 만들었다. 이 시점 카드는 `translateY(-100%) / opacity:0`
이라 창을 먼저 띄워도 화면에는 아무것도 안 보인다.

## 잡은 버그

**스누즈 병합 방향 오류.** 처음엔 `Math.abs(정규 - 스누즈) <= 5분` 으로 병합했다. 그러면
30분 알림을 스누즈해서 33분이 됐을 때 **방금 지나간 30분 정규**와 3분 차이라고 지워버린다.
스누즈가 통째로 사라지는 것. CLAUDE.md 원문도 "**다음** 정규 알림과 5분 이내" 였다.
`r.dueAt >= s.dueAt` 조건을 추가하고 회귀 테스트를 넣었다.

e2e 시나리오를 설계하다 발견했다 — 단위 테스트만 봤으면 못 잡았을 종류다.

## 트러블슈팅

**`listen EACCES ::1:1420`.** A 항목 재부팅 뒤 Windows(Hyper-V/WinNAT)가 TCP 1336–1435 를
예약해버려 Tauri 기본 dev 포트가 막혔다. 코드 문제가 아니라 환경 문제.
→ dev 포트를 **5183**(HMR 5184)로 옮겼다. `vite.config.ts` 와 `tauri.conf.json` 의 `devUrl` 둘 다.
확인 명령: `netsh interface ipv4 show excludedportrange protocol=tcp`

**`window.set_size not allowed`.** `setSize` / `scaleFactor` 는 capabilities 에 없었다.
`core:window:allow-set-size`, `core:window:allow-scale-factor` 추가.
`fitWindow` 에 실패 로그를 달아둔 덕에 한 번에 원인이 나왔다 — 조용히 삼켰으면 한참 헤맸을 것.

**검증 스크립트 두 번 삽질.**
- BOM 없는 UTF-8 `.ps1` 을 Windows PowerShell 5.1 이 CP949 로 읽어 한글 주석에서 파서 에러.
  → 일회용 검증 스크립트는 ASCII 로만 쓴다
- `GetWindowTextW` 를 `CharSet` 없이 선언하면 StringBuilder 가 ANSI 로 마샬링돼 창 제목이
  첫 글자에서 잘린다(`HourStep Overlay` → `H`). → `CharSet = CharSet.Unicode` 필수
