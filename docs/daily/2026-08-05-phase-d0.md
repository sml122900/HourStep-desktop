### T4 — 오버레이 스파이크 (이 Phase의 본체)

별도 window(`overlay`): 프레임리스 + always-on-top + skipTaskbar + 투명 + `focus: false`.

**설계**: Rust는 최소로. 위치 계산·애니메이션·상태는 전부 프론트엔드가 하고,
Rust는 "포커스 안 뺏고 띄우기/숨기기"만 담당한다.

```
트레이 [테스트 알림]
  → Rust: emit_to("overlay", "overlay://show")
  → TS: primaryMonitor() → computeOverlayWindowPosition() → setPosition()
  → TS: invoke("show_overlay_noactivate")
  → Rust: SetWindowLongPtrW(EX) + SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE) + ShowWindow(SW_SHOWNOACTIVATE)
  → TS: rAF ×2 → CSS transform 슬라이드 인
  → 버튼 클릭 → console.log + invoke("log_overlay_action") → 슬라이드 아웃 220ms → invoke("hide_overlay")
```

## 기술 결정 / 함정

### 1. `show()` 는 포커스를 뺏는다 → raw Win32로 우회

Tauri의 `WebviewWindow::show()` 는 Windows에서 `ShowWindow(SW_SHOW)` 라 창을 **활성화**하면서
포그라운드 포커스를 가져간다. 작업 중에 튀어나오는 알림이 타이핑을 끊으면 제품 가치가 없다.

`windows-sys` 로 직접:
- `SW_SHOWNOACTIVATE` + `SWP_NOACTIVATE` → 뜰 때 포커스 안 뺏음
- `WS_EX_NOACTIVATE` → **클릭해도** 포커스가 넘어오지 않음 (마우스 이벤트는 정상 전달)
- `WS_EX_TOOLWINDOW` 추가 / `WS_EX_APPWINDOW` 제거 → Alt+Tab 목록에서도 제외
  (`skipTaskbar: true` 는 작업표시줄만 막고 Alt+Tab은 남는다)
- 매 표시마다 `HWND_TOPMOST` 재설정 → 다른 topmost 창(전체화면 브라우저) 뒤로 밀리지 않게

### 2. raw로 show 했으면 hide도 raw여야 한다 ← 오늘 유일한 진짜 버그

`show_overlay_noactivate` 로 띄운 창에 `window.hide()` 를 부르면 **아무 일도 안 일어난다.**
tao는 `WindowFlags::VISIBLE` 캐시를 두고 diff만 적용하는데, `ShowWindow` 를 직접 부르면
그 캐시가 갱신되지 않아 "이미 숨겨져 있음"으로 판단하고 no-op이 된다.

증상이 고약했다 — 버튼을 누르면 카드(DOM)는 언마운트되는데 창은 그대로 남아서,
**화면 상단에 보이지 않는 클릭 차단 사각형**이 남는다. 눈에 안 보이니 원인 찾기가 어렵다.

→ `hide_overlay` 도 `ShowWindow(SW_HIDE)` 로 대칭 처리. show/hide 둘 다 tao를 우회하므로 상태가 일관된다.

**교훈**: 프레임워크의 창 상태 캐시를 우회할 거면 반대 방향도 같이 우회해야 한다. 한쪽만 하면 상태가 갈라진다.

### 3. 디버깅 삽질 기록 (사람 클릭을 유령 클릭으로 오해)

`pnpm tauri dev` 자동 실행 로그에 클릭한 적 없는 `[overlay] action = done` 이 계속 찍혀서
합성 클릭 이벤트를 의심하고 `isTrusted` 계측까지 붙였다. 실제로는 **개발자 본인이 화면에 뜬 카드를
누른 것**이었고, 위 hide 버그 때문에 카드가 안 사라지니 "클릭 안 했는데 로그가 찍힌다"로 보였을 뿐이다.

→ GUI 앱 자동 검증은 사람이 만질 수 없는 조건에서 재현해야 신뢰할 수 있다.
그래서 개발 빌드 + 환경변수 게이트로 스모크 경로를 넣었다:
`HOURSTEP_SPIKE_AUTO_OVERLAY=1` 이면 4초 뒤 자동 표시, 8초 뒤 자동 숨김.

### 4. 자동 검증으로 실측한 값 (1920×1080, 100%)

`EnumWindows` + `GetWindowLongW(GWL_EXSTYLE)` + `GetForegroundWindow` 로 외부에서 검사:

```
t=18s  vis=False  ex=0x00040118  rect=(130,130, 640x240)   ← 표시 전
t=20s  vis=True   ex=0x08000198  rect=(640,  0, 640x240)   ← 표시
t=28s  vis=False  ex=0x08000198  rect=(640,  0, 640x240)   ← 숨김
```

- `(1920−640)/2 = 640`, `y=0` → 주 모니터 중앙·최상단 정확히 일치
- `0x08000198` = `TOPMOST(0x8)` + `ACCEPTFILES(0x10)` + `TOOLWINDOW(0x80)` + `WINDOWEDGE(0x100)` + `NOACTIVATE(0x8000000)`, `APPWINDOW(0x40000)` 제거됨
- show 전후 foreground PID 불변 → 포커스 미탈취
- 다른 실행에서는 Unity 에디터가 포그라운드인 상태로 카드가 떴고 포커스가 그대로 유지됐다
- 메모리 약 32MB (dev 빌드) — Electron 대비 목표 달성

검사 스니펫 (PowerShell, 필요할 때 재사용):

```powershell
Add-Type -TypeDefinition @"
using System;using System.Text;using System.Collections.Generic;using System.Runtime.InteropServices;
[StructLayout(LayoutKind.Sequential)] public struct R7 { public int L,T,R,B; }
public class W7 {
  delegate bool EnumProc(IntPtr h, IntPtr l);
  [DllImport("user32.dll")] static extern bool EnumWindows(EnumProc cb, IntPtr l);
  [DllImport("user32.dll", CharSet=CharSet.Unicode)] static extern int GetWindowTextW(IntPtr h, StringBuilder s, int n);
  [DllImport("user32.dll")] static extern uint GetWindowThreadProcessId(IntPtr h, out uint pid);
  [DllImport("user32.dll")] static extern bool IsWindowVisible(IntPtr h);
  [DllImport("user32.dll")] static extern int GetWindowLongW(IntPtr h, int i);
  [DllImport("user32.dll")] static extern bool GetWindowRect(IntPtr h, out R7 r);
  [DllImport("user32.dll")] static extern IntPtr GetForegroundWindow();
  public static string Overlay(uint t) { string res="(none)";
    EnumWindows((h,x)=>{ uint p; GetWindowThreadProcessId(h,out p); if(p==t){ var sb=new StringBuilder(256); GetWindowTextW(h,sb,256);
      if(sb.ToString()=="HourStep Overlay"){ R7 r; GetWindowRect(h,out r);
        res=string.Format("vis={0,-5} ex=0x{1:X8} rect=({2},{3},{4}x{5})", IsWindowVisible(h), (uint)GetWindowLongW(h,-20), r.L, r.T, r.R-r.L, r.B-r.T); } } return true; }, IntPtr.Zero); return res; }
  public static uint FgPid() { uint p; GetWindowThreadProcessId(GetForegroundWindow(), out p); return p; }
}
"@
$p = Get-Process hourstep-desktop | Select-Object -First 1
[W7]::Overlay([uint32]$p.Id); [W7]::FgPid()
```
