# 2026-08-07 — D0 수동 검증 종결

자동 검증(2026-08-05)으로 닫지 못하고 남아 있던 4건을 사용자가 직접 확인했다.
**전부 통과. 실패 항목 없음.** 체크리스트 원본은 `docs/phase-d0-verification.md`.

환경: Windows 11, 1920×1080 단일 모니터, 배율 100%.

## 왜 사람이 해야 했나

`CLAUDE.md` 「검증 정책」이 사용자 데스크톱 세션에 합성 입력(SendInput) 주입을 금지한다.
그래서 남은 항목은 두 부류였다.

1. **지각 판단** — 화면에 실제로 보이는가 (C, E-4')
2. **실제 입력 장치** — 진짜 마우스 클릭이 창에 닿는가 (B-2', B-4b)
3. **재부팅** — A

2번은 원래 "Windows Sandbox/VM E2E 몫"으로 미뤄뒀는데, **사용자가 직접 마우스로 클릭하는 것은
합성 입력이 아니므로 정책 대상이 아니다.** 격리 환경을 세우는 것보다 이쪽이 빠르고 근거도 강했다.

## 결과

### B-2' / B-4b — 실제 마우스 클릭

Chrome 검색란에 커서를 둔 상태에서 카드를 띄우고, **진짜 마우스로** 버튼을 클릭한 뒤
마우스를 건드리지 않고 바로 타이핑했다.

- 클릭이 `WS_EX_NOACTIVATE` 오버레이에 정상 전달됨 (3버튼 모두 각각 `done`/`snoozed`/`skipped` 로그)
- 클릭 **직후**에도 타이핑이 Chrome 검색란에 그대로 이어짐 → **포커스 미탈취**

`SW_SHOWNOACTIVATE` + `WS_EX_NOACTIVATE` 조합이 "클릭은 받되 포커스는 안 뺏는다"를
실제로 달성한다는 게 실측으로 확인됐다. 금지된 SendInput 근거를 대체 완료.

### C — 전체화면 위 표시

`--debug-cmd` 반복 모드(20초 주기, 카드 8초 표시)로 각 전체화면 모드에 들어가 관찰했다.

| 모드 | 결과 |
| --- | --- |
| C-1 유튜브 플레이어 Fullscreen API (`F`) | 뜸 |
| C-2 브라우저 F11 (자동 검증 완료분) | 뜸 |
| C-3 팟플레이어 전체화면 | 뜸 |
| C-4 게임 borderless | 뜸 |
| C-5 게임 exclusive | **뜸** |

**실패 목록이 비었다.** C-5는 실패를 예상하고 만든 항목이었다 — Windows가 배타적 전체화면 앱이
포그라운드일 때 topmost 창을 억제하기 때문. 그런데 떴다.

⚠️ **다만 이 결과는 아직 반쪽이다.** C-4/C-5의 게임명이 기록되지 않았고, C-5가 정말로 배타적
모드였는지 확증되지 않았다. 최근 게임은 옵션에 `전체화면` 이라고 표기해도 DXGI flip model 로
내부적으로 borderless 인 경우가 많다. 그러면 C-5는 C-4를 두 번 잰 것에 불과하다.
**「알려진 한계 2」를 정식 폐기하지 않고 D3 재확인 대상으로 남겨둔 이유다.**

### E-4' — 트레이 아이콘 소멸

트레이 `종료` 직후 아이콘이 **즉시** 사라졌다. 유령 아이콘 없음.
(프로세스 종료 자체인 E-4는 `--debug-cmd quit` 으로 이미 자동 검증됨)

### A — 재부팅 자동 상주

NSIS 설치본(`HourStep_0.1.0_x64-setup.exe`)으로 검증.

- A-1: `HKCU:\...\Run` 에 `HourStep = "…\AppData\Local\HourStep\HourStep.exe" --autostart`
- A-2: 재부팅 후 메인 창이 **깜빡임도 없이** 안 뜸 → `--autostart` 분기 정상
- A-3: 트레이에 아이콘 상주
- A-4: 설치본(릴리스 빌드)에서도 카드 정상 동작

dev 빌드에서 되던 게 릴리스에서 깨지는 경우가 흔한데(에셋 경로 등) 그런 문제는 없었다.

## 트러블슈팅

**여러 줄 PowerShell 명령이 잘려 붙여넣어짐.** 문서에 적어둔 A-1 확인 명령이 2줄이었는데
첫 줄만 실행돼 `Get-ItemProperty` 가 `Path` 를 되물으며 멈췄다.
→ **검증 문서에 넣는 명령은 한 줄로 쓴다.** 대체한 한 줄:

```powershell
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' | Select-Object *Hour* | Format-List
```
