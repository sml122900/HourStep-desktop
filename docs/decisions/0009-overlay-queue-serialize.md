# 0009. 겹친 발화는 병합하지 않고 큐로 직렬화한다

- 날짜: 2026-08-09
- Phase: D2.7
- 상태: 채택
- 관련: `src/core/overlayQueue.ts`, `src/windows/overlay/OverlayWindow.tsx`,
  `docs/decisions/0005-overlay-window-fits-card.md`

## Problem

오버레이 창은 **하나**다(0005: 창을 카드 실크기로 맞춘다). 그런데 발화는 겹친다 —
30분 물마시기와 60분 눈휴식은 60분마다 같은 초에 도래하고, D2.7 에서 [완료]가
카운트다운을 시작하면 카드가 최대 10분까지 화면에 머문다. 그 사이 도래한 알림을
그대로 띄우면 **보고 있던 카드를 덮어쓴다.** 눈을 감고 1분을 세던 사람은 카드가 언제
바뀌었는지도 모른다.

## Decision

**병합하지 않는다. 큐에 재웠다가 한 건씩 이어서 띄운다.**

- 카드가 떠 있는 동안(카운트다운 포함) 도래한 occurrence 는 큐에 적재하고 **즉시 띄우지 않는다**
- 현재 카드가 끝나면(done / snoozed / skipped / 카운트다운 종료) 큐에서 하나 꺼내 띄운다
- 큐 항목은 **원래 `dueAt` 을 유지한다**. 지연은 사실이고 그 사실을 지우지 않는다
- 상한 5건. 넘으면 **오래된 것부터** 버린다 (`skipped` 로 기록하지 않고 로그만 남긴다)
- **세션이 끝나면 큐를 통째로 버린다**
- 큐 적재는 **무음**이다. 알림음은 카드가 실제로 뜰 때만 울린다
- 스누즈는 큐와 무관하다 — 기존대로 스케줄러 경로로 다시 도래한다

판단 로직은 `src/core/overlayQueue.ts` 순수 함수 + vitest 로 뺐다. 오버레이 컴포넌트에는
ref 하나(`queueRef`)만 남는다.

### 왜 병합이 아닌가

"물마시기 + 눈휴식"을 한 장에 합치는 안이 있었다. 버렸다.

- 두 행동은 **둘 다 해야 할 일**이다. 한 장에 합치면 [완료]가 무엇을 완료한 건지 모호해진다
- 기록이 뭉개진다. `CompletionLog` 는 행동별 실천율의 근거인데, 합친 카드의 [완료]를
  두 건으로 쪼개 적으면 "실제로 물을 마셨는가"를 앱이 지어내는 셈이다
- 행위 시간(D2.7)과 상극이다. 스트레칭 60초와 물마시기 0초를 어떻게 합쳐 세나

### 왜 덮어쓰기가 아닌가 (가장 단순한 안)

지금까지의 동작이 사실상 이것이었다(`activeRef` 가 있으면 tick 이 그냥 지나갔으므로
정확히는 "새 것을 버리기"였다). 버려진 알림은 `firedRef` 에 소진 표시가 되어 다시 오지 않는다 —
**조용히 사라진다.** 물마시기를 30분마다 켜 뒀는데 스트레칭 카운트다운과 겹칠 때마다
한 건씩 증발하면, 실천율은 낮아지지 않고 그냥 알림이 안 온다. 사용자는 이유를 알 수 없다.

### 왜 꺼낼 때 STALE_MS 를 다시 보지 않나

밀린 알림 소진(`STALE_MS` 2분)은 **절전 복귀 시 카드 폭탄**을 막으려고 있다. 큐에서 밀린
이유는 다르다 — 앞 카드를 사용자가 성실히 하고 있었기 때문이다. 그걸 "너무 오래돼서
버림"으로 처리하면 열심히 쉰 사람만 알림을 못 받는다. 대신 상한 5건이 폭주를 막는다.

### 왜 5건인가, 왜 오래된 것부터 버리나

5건이 쌓였다면 이미 한참 밀린 상태다. 그때 붙잡고 있어 봐야 "10분 전에 왔어야 할 알림"을
보여줄 뿐이라 최신 것이 더 쓸모 있다. 버린 것을 `skipped` 로 적지 않는 이유는 그게
**사용자가 건너뛴 게 아니라 앱이 못 보여준 것**이기 때문이다 — 실천율을 사용자 탓으로
왜곡하지 않는다. 대신 `[debug] queue push … dropped=…` 로 로그에는 반드시 남긴다.

## Consequences

- 「알려진 한계 6. 동시 due 는 큐로 밀린다」가 이제 실제로 큐다. 겹친 알림이 사라지지 않는다
- 카드가 연달아 뜰 수 있다. 이어 띄울 때는 창을 숨겼다 다시 띄우지 않는다(깜빡임) —
  슬라이드 아웃이 끝난 자리에서 다음 카드가 다시 슬라이드 인 하고, 알림음 ① 은 매번 울린다
- 큐는 **메모리에만** 있다. 앱을 끄면 사라진다 — 세션 종료 시 버리는 것과 같은 이유다
- 큐 상태는 화면에 안 보인다. 자동 검증 창구로 `--debug-cmd queue-dump` 를 뒀다
